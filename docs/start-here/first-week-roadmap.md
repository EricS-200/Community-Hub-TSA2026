# A first-week roadmap

**Audience:** a student joining a FIRST team for the first time. **Outcome:** complete one safe, reviewable contribution.

## Day 1 — Listen and map the work

Meet the team, locate safety rules and emergency procedures, and learn how the team stores design files and code. Ask to observe an active project.

## Days 2–3 — Choose one small deliverable

Pick a task that can be completed without blocking other work: label components in a CAD assembly, write a simple simulation, build a parts spreadsheet, or revise an outreach email.

## Days 4–5 — Produce and explain

Save your work in the right shared location. Add a short note: **purpose → approach → evidence → next question**. Ask someone to review it.

{% hint style="success" %}
**Done means:** a teammate can find your work, understand the goal, and reproduce or evaluate the result.
{% endhint %}

## Reflection

* What surprised you?
* What would you test differently next time?
* What should the next new student know?
