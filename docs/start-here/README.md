You do not need to know everything before you can contribute. Select your program, then complete a small project with a clear test.

## Which FIRST program?

| Program                              | Typical focus                                 | Start with                                            |
| ------------------------------------ | --------------------------------------------- | ----------------------------------------------------- |
| **FIRST LEGO League (FLL)**          | Exploring engineering, design, and teamwork   | Building, iteration, and research                     |
| **FIRST Tech Challenge (FTC)**       | Design, build, and code a student-built robot | Basic mechanisms, drivetrain control, and sensors     |
| **FIRST Robotics Competition (FRC)** | Large-scale collaborative robot development   | Safety, subsystem architecture, fabrication, and code |

Official entry points: [FIRST LEGO League](https://www.firstinspires.org/programs/fll/), [FIRST Tech Challenge](https://www.firstinspires.org/programs/ftc/), [FIRST Robotics Competition](https://www.firstinspires.org/programs/frc/).

{% hint style="warning" %}
**Season materials change.** Treat the current official game manual, team updates, inspection requirements, and safety guidance as the source of truth. Do not use an older tutorial as a substitute for current rules.
{% endhint %}

## Your first contribution

{% stepper %}
{% step %}
### Observe

Ask your team what currently slows them down. Find a small task with an owner, deadline, and success criterion.
{% endstep %}

{% step %}
### Learn one tool

Choose one: a CAD sketch, a simple program, a wiring diagram, a test checklist, or a sponsor research sheet.
{% endstep %}

{% step %}
### Make something testable

Produce a small artifact: a dimensioned part, repeatable code behavior, or a one-page project brief.
{% endstep %}

{% step %}
### Review it together

Ask someone else to reproduce or critique your work. Record the change you made after feedback.
{% endstep %}
{% endstepper %}

## Suggested starter projects

* **Software:** Read a gamepad input and use it to control a simulated or safely supported subsystem.
* **CAD:** Model a simple plate with mounting holes and create a manufacturing drawing.
* **Electrical:** Build and label a diagram for a sensor circuit; have a qualified mentor review it before physical wiring.
* **Outreach:** Identify three potential community partners and draft a concise, specific request.
* **Documentation:** Turn one thing your team explains repeatedly into a page with screenshots or a checklist.

Continue with [Programming](../programming/), [CAD & design](../cad-and-design/), or [Team operations](../team-operations/).
