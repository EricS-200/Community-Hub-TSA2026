# Kentucky teams & season links

A one-stop local index. KY FIRST Robotics is the regional source for Kentucky event and funding information; FIRST publishes official season rules and program materials.

## In Kentucky

| Resource                                                              | Why open it                                    |
| --------------------------------------------------------------------- | ---------------------------------------------- |
| [KY FIRST Robotics](https://www.kyfirstrobotics.org/)                 | Regional news, events, and programs            |
| [KY FIRST — FRC](https://www.kyfirstrobotics.org/frc)                 | FRC resources and local opportunities          |
| [KY FIRST — FTC](https://www.kyfirstrobotics.org/ftc)                 | FTC events, workshops, and program information |
| [KY FIRST — FLL](https://www.kyfirstrobotics.org/fll)                 | FLL events, season information, and support    |
| [KY FIRST — Team grants](https://www.kyfirstrobotics.org/team-grants) | Grant opportunities and funding information    |

## For new Kentucky teams

Start by identifying the relevant program and season, then contact the regional organization about events and support. Use the [resource library](./) to help students acquire technical and nontechnical skills while the team gets established.
