# FTC: build & code

**For:** FTC rookies and experienced teams looking for reliable references. Rules and software setup come from FIRST; general build techniques come from established community and vendor guides.

## Start with the supported stack

| Resource                                                                                                         | Format                 | Best for                                          |
| ---------------------------------------------------------------------------------------------------------------- | ---------------------- | ------------------------------------------------- |
| [FTC Docs](https://ftc-docs.firstinspires.org/en/latest/)                                                        | Official documentation | Robot configuration, programming, troubleshooting |
| [FTC rookie-team hub](https://ftc-docs.firstinspires.org/en/latest/persona_pages/rookie_teams/rookie_teams.html) | Official guide         | New-team setup and first milestones               |
| [FIRST FTC programming resources](https://www.firstinspires.org/resources/library/ftc/programming-resources)     | Official directory     | Blocks, Java, and current software                |
| [FTC team resources](https://ftc-resources.firstinspires.org/ftc/team)                                           | Official directory     | Season tools and team resources                   |
| [REV Robotics Docs](https://docs.revrobotics.com/)                                                               | Vendor docs            | REV hardware, firmware, controls                  |

## Learn mechanical design and software

| Resource                                                                                                         | Format                | Best for                                                    |
| ---------------------------------------------------------------------------------------------------------------- | --------------------- | ----------------------------------------------------------- |
| [Game Manual 0](https://gm0.org/en/latest/)                                                                      | Community textbook    | Broad introduction to FTC design, building, and programming |
| [GM0: common mechanisms](https://gm0.org/en/latest/docs/common-mechanisms/)                                      | Reference guide       | Intakes, lifts, claws, drivetrain concepts                  |
| [GM0: programming options](https://gm0.org/en/latest/docs/software/getting-started/options-for-programming.html) | Guide                 | Choosing a suitable FTC programming workflow                |
| [goBILDA TV](https://www.gobilda.com/gobildatv)                                                                  | Video library         | Build techniques, mechanisms, prototype ideas               |
| [goBILDA starter robot guide](https://www.gobilda.com/ftc-starter-bot-resource-guide-decode/)                    | Archived season build | Design and code walkthrough for a 2025–26 robot             |
| [FTC Community Video](https://ftccv.org/)                                                                        | Videos                | Team robot reviews and community demonstrations             |
