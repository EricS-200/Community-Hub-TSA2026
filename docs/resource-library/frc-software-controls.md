# FRC: software & controls

**For:** FRC programmers, controls students, and software mentors. Start with WPILib for supported APIs and architecture; use community training to understand how teams apply them.

## Beginner pathway

| Resource                                                                                                                | Format                 | Why use it                                                         |
| ----------------------------------------------------------------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------------ |
| [WPILib Zero to Robot](https://docs.wpilib.org/en/stable/docs/zero-to-robot/introduction.html)                          | Official documentation | Setup, basic wiring, programming, deployment                       |
| [Creating a robot program](https://docs.wpilib.org/en/stable/docs/software/vscode-overview/creating-robot-program.html) | Official guide         | Learn the project templates and desktop support                    |
| [WPILib example projects](https://docs.wpilib.org/en/stable/docs/software/examples-tutorials/wpilib-examples.html)      | Example code           | See a working pattern before writing your own                      |
| [LearnFRC — programming videos](https://learnfrc.com/videos)                                                            | Video lessons          | Follow an ordered explanation of basic concepts                    |
| [FRC Canada Java tutorial series](https://archive.firstroboticscanada.org/cancode/frc/)                                 | Archived videos        | Understand command/subsystem concepts; 2019 API details may differ |
