# Watch & learn

Videos are great for seeing a technique in practice. The written resource alongside each recommendation is where to check current details. **Older videos are labeled** because robots, rules, and software change.

## Start with these

### FRC: an accessible robot-design case study

[**Robonauts 118 — Everybot 2026**](https://www.youtube.com/watch?v=FudOjq7lNGk) · FRC · Robot concept · 2026 season

A practical example of designing around affordability, available tools, and achievable game objectives. Treat the game-specific design as a historical case study, not a recipe for the next season.

{% embed url="https://www.youtube.com/watch?v=FudOjq7lNGk" %}

### FTC: robot-building basics

[**Robot-Building Basics**](https://www.youtube.com/watch?v=rE2yYXQt5Yo) · FTC · Beginner build video

A visual introduction to a starter robot's mechanical components. Cross-reference current vendor build documentation before assembling competition hardware.

{% embed url="https://www.youtube.com/watch?v=rE2yYXQt5Yo" %}

### FTC: get a starter robot moving with Blocks

[**goBILDA — FTC Starter Robot Blocks Programming Guide**](https://www.youtube.com/watch?v=Sjt3rufGoDs) · FTC · Beginner programming · Older tutorial

Walks through Blocks-based starter code. The overall concepts transfer; use [FTC Docs](https://ftc-docs.firstinspires.org/en/latest/) for current software and device setup.

{% embed url="https://www.youtube.com/watch?v=Sjt3rufGoDs" %}

## CAD on video

### Onshape: begin with sketching

[**Onshape FRC — Getting Started with Sketch**](https://www.youtube.com/watch?v=FIikVGmQLu0) · FRC/CAD · 2026

A focused starting point for sketch-based modeling; pair with the [FRCDesign learning course](https://frcdesign.org/learning-course/).

{% embed url="https://www.youtube.com/watch?v=FIikVGmQLu0" %}

### Onshape: assemblies and detailing

[**Onshape Assembly and Detailing Tutorial**](https://www.youtube.com/watch?v=7oipFYGertc) · FRC/CAD · 2026

For students who have already modeled simple parts and need assembly structure and drawings.

{% embed url="https://www.youtube.com/watch?v=7oipFYGertc" %}

## Outreach & business

### Inventive outreach, presented through FIRST

[**Inventive Outreach and Your Team**](https://www.youtube.com/watch?v=tw8kkre6hK4) · FRC · Community engagement

A presentation by Sarah Heimlich, linked from FIRST's official team-management resource library. Discuss how the ideas could work with your team's actual capacities.

{% embed url="https://www.youtube.com/watch?v=tw8kkre6hK4" %}
