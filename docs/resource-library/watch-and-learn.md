# Watch & learn

**Watch actively:** choose one question before pressing play, then make or explain something afterward. Videos below are English unless labeled otherwise. Older examples teach methods; current publisher documentation supplies installation and season details.

## Design and build

### Robonauts 118 — Everybot 2026

A short visual FRC design case study from Robonauts 118 (1 minute, 19 seconds). The checked player did not offer captions; the written context and task below provide the essential learning prompt. Watch how a constrained design selects achievable objectives; do not copy game-specific assumptions into another season.

{% embed url="https://www.youtube.com/watch?v=FudOjq7lNGk" %}

[Watch at YouTube](https://www.youtube.com/watch?v=FudOjq7lNGk) · **Use it:** Name one capability the robot prioritizes and one tradeoff. Compare with your own team’s tools and time.

### Onshape — Basic Sketch Geometry

An official English introduction to sketch geometry. Pair it with the [FRCDesign course](https://frcdesign.org/learning-course/) or [Onshape Intro to CAD](https://learn.onshape.com/learning-paths/intro-to-cad).

{% embed url="https://www.youtube.com/watch?v=xvn9hD7KMVs" %}

[Watch at YouTube](https://www.youtube.com/watch?v=xvn9hD7KMVs) · **Use it:** Create a small sketch, then explain which geometry is constrained and why.
