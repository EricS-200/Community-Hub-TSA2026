## Looking for something less obvious?

Go to [Tools & workflows](../tools-workflows/) for Fusion and Onshape MCPs, coding agents, log analysis, and underused software. These resources focus on _how to accomplish useful tasks_, not just which apps exist.

## How resources are selected

A resource earns a place here if it has a clear audience, a practical use, credible authorship, and more learning value than a generic search result. We label archival tutorials, distinguish community guidance from official rules, and link to creators directly.

{% hint style="warning" %}
**Current-season rules always win.** A well-made video from a previous year may teach useful principles while showing outdated hardware, firmware, code, or game details.
{% endhint %}
