## When you already know the basics

Use [Tools & workflows](../tools-workflows/) to explore overlooked capabilities: connect CAD through MCP, investigate an intermittent failure, practice offline, or ask a coding agent to explain your actual project.

## Read the labels

* **Official:** maintained by the program or tool publisher. A software vendor is authoritative about its tool, not FIRST competition rules.
* **Community:** teaching and field experience from teams and volunteers; assess compatibility and assumptions.
* **Archived:** useful concepts, with old APIs, UI or game details to check.
* **Pilot:** a proposed exercise here; it has acceptance criteria but is not a claim of a hardware-tested deployment.

{% hint style="info" %}
Start with one complete course rather than collecting twenty introductions. Pair it with one task your team actually needs, and ask a teammate to review the result.
{% endhint %}
