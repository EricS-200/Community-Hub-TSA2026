# FLL & LEGO learning

**For:** FIRST LEGO League students, coaches, and families. Most work here is best supported by hands-on practice and a good coach; start with the official challenge materials.

## Official entry points

| Resource                                                                                                                                        | Format               | Why use it                                              |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- | ------------------------------------------------------- |
| [FIRST LEGO League program](https://www.firstinspires.org/programs/fll/get-started)                                                             | Official guide       | Learn the divisions, participation, and getting started |
| [FLL technical resources](https://www.firstinspires.org/resources/library/fll/technical-resources)                                              | Official directory   | Current robotics technology and program materials       |
| [LEGO Education season materials](https://education.lego.com/en-us/first-lego-league/season-materials/)                                         | Season resources     | Game materials, instructions, and related materials     |
| [LEGO Education SPIKE Prime video tutorials](https://education.lego.com/en-us/product-resources/spike-prime/teacher-resources/video-tutorials/) | Videos               | Hardware and software introduction                      |
| [Getting started with SPIKE Prime](https://education.lego.com/en-us/start/spike-prime/)                                                         | Interactive tutorial | First assembly and software setup                       |

## Coach note

{% hint style="info" %}
The innovation project is about research and iteration, not only about scoring robot-game points. Let students make decisions and explain how they arrived at them.
{% endhint %}

For Kentucky events and local information, use [KY FIRST FLL](https://www.kyfirstrobotics.org/fll). For current rules, check FIRST's latest official season materials.
