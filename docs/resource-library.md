# Resource library

A shortlist of high-value references. Prefer original documentation for rules and technical specifications; use community tutorials to build intuition and examples.

## Official and technical references

| Resource                                                    | Best for                                        | Type                  |
| ----------------------------------------------------------- | ----------------------------------------------- | --------------------- |
| [FIRST](https://www.firstinspires.org/)                     | Programs, season information, official policies | Official              |
| [FRC resources](https://www.firstinspires.org/robotics/frc) | FRC program and competition resources           | Official              |
| [FTC Docs](https://ftc-docs.firstinspires.org/)             | FTC software and hardware guidance              | Official              |
| [WPILib Docs](https://docs.wpilib.org/en/stable/)           | FRC programming, control, and simulation        | Official project docs |
| [Onshape Learning Center](https://learn.onshape.com/)       | CAD fundamentals and guided exercises           | Training              |
| [REV Robotics Docs](https://docs.revrobotics.com/)          | Vendor hardware and integration references      | Vendor docs           |
| [GitHub Skills](https://skills.github.com/)                 | Git, issues, pull requests, collaboration       | Interactive courses   |

## Watch and practice

{% tabs %}
{% tab title="Programming" %}
**Start with a real task, not a playlist.** Use [WPILib Docs](https://docs.wpilib.org/en/stable/) or [FTC Docs](https://ftc-docs.firstinspires.org/) alongside a short lesson. After each lesson, implement the behavior on a safe test setup and explain what it does without the video.
{% endtab %}

{% tab title="CAD" %}
Complete a [Learning Center](https://learn.onshape.com/) course, then remodel a familiar component from measurements. Compare the digital part to the physical part and record differences.
{% endtab %}

{% tab title="Team skills" %}
Review [FIRST program information](https://www.firstinspires.org/) and sample outreach plans. Practice a two-minute team introduction; have someone unfamiliar with robotics tell you what they understood.
{% endtab %}
{% endtabs %}

## Evaluate any resource before sharing

1. Who authored it, and are they qualified to make the claim?
2. Is it current for the program, season, and software version?
3. Is it a tutorial or an authoritative rule/specification?
4. Can a student reproduce the outcome?
5. Does it acknowledge safety, limitations, or assumptions?
