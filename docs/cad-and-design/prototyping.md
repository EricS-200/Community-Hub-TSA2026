# From model to prototype

A prototype is an experiment. Its job is to answer a question as cheaply and safely as possible.

## Choose the smallest test

| Unknown             | Low-cost experiment                          |
| ------------------- | -------------------------------------------- |
| Mechanism geometry  | Cardboard / simple printed mockup            |
| Fit and access      | Partial assembly with actual fasteners       |
| Structural behavior | Controlled load test with mentor supervision |
| Repeatability       | Multiple trials under recorded conditions    |
| Maintenance         | Time a realistic replacement operation       |

{% hint style="info" %}
Prototype materials rarely match final-material strength, wear, or thermal behavior. Validate final requirements with appropriate methods.
{% endhint %}

## Document the iteration

1. **Hypothesis:** what must be true?
2. **Setup:** what did you build and measure?
3. **Observation:** what actually happened?
4. **Change:** what will you alter?
5. **Retest:** did the change work?

Link to [Design review checklist](design-review.md) and preserve revision history.

Further learning: [Onshape Learning Center](https://learn.onshape.com/).

## Use a test that can change the decision

Pair the experiment with [FRCDesign’s handbook](https://www.frcdesign.org/design-handbook/) or [GM0’s mechanism references](https://gm0.org/en/latest/docs/common-mechanisms/). Write the result that would make the team reject the current design before collecting data. Preserve failed prototypes in the design log so next year’s students do not repeat them without context.
